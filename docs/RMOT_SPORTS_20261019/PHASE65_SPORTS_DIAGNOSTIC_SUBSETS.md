# Phase 65 — Refer-Sports diagnostic subset registry

Status: `CANDIDATE_SUBSETS_REGISTERED_METRICS_NOT_RUN`

The canonical Refer-Sports manifest was scanned without reading test GT into a
model or selecting a checkpoint. Expression text and audited target-set
metadata register candidates for four planned diagnostics:

| subset | train expressions | historical-test expressions | status |
| --- | ---: | ---: | --- |
| S1 same-uniform identity candidate | 104 | 81 | candidate; negative labels remain UNKNOWN |
| S2 temporally valid referring candidate | 54 | 40 | candidate; event completeness not verified |
| S3 group/subset candidate | 118 | 95 | candidate; framewise negatives remain UNKNOWN |
| S4 occlusion/identity persistence | 0 | 0 | `INSUFFICIENT_LABELS` |

S1–S3 are expression-level candidate registries, not verified semantic
subsets. The source audit explicitly defines outside-interval and negative
states as `UNKNOWN`, so this phase does not convert them to FALSE and does not
compute accuracy, F1, HOTA or delay metrics. S4 has no explicit occlusion
annotation in the canonical manifest and remains unavailable until a bounded
manual annotation audit supplies it.

The machine-readable candidate IDs are generated by
`scripts/build_sports_diagnostic_subsets.py`. They are intended to constrain
later train/validation analysis; the historical test candidates may only be
used for the final preregistered evaluation after all choices are frozen.
