# Refer-Sports dataset audit

Status: `COMPLETE WITH SOURCE-COUNT WARNING`

The canonical audit is `PHASE2_SPORTS_DATA_AUDIT.md` and the machine-readable
manifest is generated by `scripts/audit_refer_sports.py`.

- The verified archive contains 41 video IDs and 323 expression JSON files.
- The historical source lists contain 22 training videos / 181 expressions
  and 19 test videos / 142 expressions.
- One archived test expression is absent from `seqmap_sports.txt`; it is
  retained and flagged rather than silently dropped.
- Every expression video maps to a local SportsMOT frame sequence, and target
  IDs are checked against the global `labels_with_ids` namespace.
- Missing frame keys and targets outside annotated intervals remain
  `UNKNOWN`; the converter never invents negative labels.
- Image dimensions and frame counts are measured from the frame tree. FPS is
  `UNKNOWN` where no source container metadata exists.

The attachment's approximate 492-expression statistic does not match the
verified 323-file archive. This unresolved discrepancy is preserved as an
audit warning and is not corrected by inference. No test annotation is passed
to a model or tracker; evaluation GT is assembled only for offline TrackEval.
