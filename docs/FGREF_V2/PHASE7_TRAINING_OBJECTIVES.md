# Phase 7 training objectives

Status: `OPTIONAL_OBJECTIVE_MODULE_IMPLEMENTED`,
`IDENTITY_COUNTERFACTUAL_SUPERVISION_NOT_ENABLED`.

## Implemented interfaces

`models/fgref_v2/training_losses.py` provides:

- the existing independent per-candidate referring BCE contract with an
  explicit validity mask;
- a supervised contrastive identity loss over explicit nonnegative track IDs;
- an optional counterfactual referring BCE over verified positive/negative
  pairs;
- a loss composer that exposes `loss_fgref_v2_identity` and
  `loss_fgref_v2_counterfactual` only when the caller supplies the required
  evidence and masks.

Rows with unknown IDs are ignored by the identity objective. A batch without a
same-ID positive pair returns a differentiable zero; it does not invent a
positive or treat an unrelated track as one. Counterfactual targets are never
generated by lexical substitution in this module.

## Current supervision boundary

The legacy training graph still optimizes its original classification, box,
GIoU, referring, and existing temporal losses. The new identity and
counterfactual terms are not added to the reported training runs because the
current audit has not verified suitable identity-consistency or
counterfactual annotations for Refer-Sports/Refer-KITTI. This is deliberate:
the two-step TAM smoke in `PHASE5_TAM_RESULTS.md` verifies only that the
existing referring loss reaches TAM-v2.

Once annotations are audited, the controlled objective matrix is:

| Variant | Objective |
| --- | --- |
| L0 | legacy detection + box + referring + existing temporal losses |
| L1 | L0 + identity consistency |
| L2 | L0 + verified counterfactual supervision |
| L3 | L0 + identity + counterfactual terms |

Weights must be selected on a legal grouped validation split and fixed before
the sealed evaluation. No result is claimed for L1–L3 yet.
