The lexical categories are diagnostic regular expressions, not human labels.
The JSON files do contain frame-indexed target IDs and explicit valid label
frames; this scan does not establish that an action is false outside its
listed interval. There are 51 exact sentence strings occurring across more
than one video, so sentence equality cannot be used as a leakage-free group
key. The video IDs also collapse into ten source-name prefixes, which is a
potential source-video grouping signal rather than proof of a split leak.

The available manifests are all training-style files. No independent test
manifest was found by this bounded audit. Therefore train/test isolation,
match-level isolation, LLM-rewrite lineage isolation, and sealed-evaluation
status remain **unverified**. The historical 22-video protocol is retained as
an archive-compatible candidate only.

## Audit limits

The Refer-KITTI scan verified the existence of every image and box-file frame
referenced by the 323 expression JSON files, but it did not decode every image,
reconstruct SportsMOT match identity, or verify the provenance of generated
language rewrites. It therefore does not claim action interval validity,
source-video isolation, or leakage-free rewriting.

Before training, the next audit must produce a manifest grouped by source
video/match and expression lineage, and must check:

- train/test source-video and match overlap;
- original-expression and rewrite overlap;
- frame/label/expression one-to-one resolution;
- target count and valid temporal interval distributions;
- number, color, relation, action, group, and occlusion coverage;
- whether unannotated action time is unknown rather than negative.

The historical 22/19 split may be retained for comparability, but it must not
be described as a newly sealed test set if it has already guided method
selection.
